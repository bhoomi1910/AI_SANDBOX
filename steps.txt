================================================================================
  AI-POWERED INTELLIGENT SANDBOX  —  SETUP & RUN GUIDE  (steps.txt)
  Deterministic Static Malware Analysis + AI Interpretation + PDF Reports
  B.E. Major Project
================================================================================

TL;DR — run the full stack:
    1) Backend:  cd backend
                 python -m venv .venv
                 .\.venv\Scripts\Activate.ps1        (Windows)
                 source .venv/bin/activate           (Linux/macOS)
                 pip install -r requirements.txt
                 copy .env.example .env              (or: cp .env.example .env)
                 uvicorn app.main:app --reload --port 8000
    2) Frontend: cd frontend
                 npm install
                 copy .env.example .env              (or: cp .env.example .env)
                 npm run dev
    3) Open  http://localhost:5173  →  click "Access console"

The sample is NEVER executed. All analysis is deterministic static analysis
performed on the server; the AI (if installed) only interprets the results.

================================================================================
  2. RUN THE BACKEND  (FastAPI — REQUIRED for live data)
================================================================================

  Windows (PowerShell):
    cd backend
    python -m venv .venv
    .\.venv\Scripts\Activate.ps1
    pip install -r requirements.txt
    copy .env.example .env
    uvicorn app.main:app --reload --port 8000

  Linux/macOS:
    cd backend
    python3 -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt
    cp .env.example .env
    uvicorn app.main:app --reload --port 8000

  • Interactive API docs ... http://localhost:8000/docs
  • Health check ........... http://localhost:8000/api/health

  Uses SQLite out of the box — NO database setup required.
  Always install into the virtual environment so the PINNED versions in
  requirements.txt are used.


================================================================================
  3. RUN THE FRONTEND  (React + Vite)
================================================================================

  Windows (PowerShell) / Linux/macOS:
    cd frontend
    npm install
    copy .env.example .env     (or: cp .env.example .env)
    npm run dev

  Open http://localhost:5173 → login screen → click "Access console".

  Try the workflow:
    Dashboard → Upload Sample (drag any file, or use the demo sample)
    → Investigation Queue → open a case
    → Static Analysis → Mitre → AI Investigation → Report → "Download report"

  The default .env sets VITE_USE_BACKEND=true, so the frontend calls the backend
  through the Vite /api proxy (http://localhost:8000).

  DEMO MODE (no backend):
    Set VITE_USE_BACKEND=false in frontend/.env and restart npm run dev.
    The whole workflow then runs on the built-in mock dataset — Dynamic, Network
    and Threat Intel pages always use mock content; Static/Mitre/AI/Report pages
    use real backend data when available.


================================================================================
  4. OPTIONAL — LOCAL AI (Ollama)
================================================================================

  1) Install Ollama:  https://ollama.com
  2) Pull a free model, e.g.:  ollama pull qwen3:4b
  3) In backend/.env:
       OLLAMA_URL=http://localhost:11434
       AI_MODEL=                  # empty = auto-discover the first installed model
  4) Restart the backend.

  Without Ollama the AI sections render a clear "unavailable" state; all other
  analysis still works. The AI only interprets deterministic output — it can
  never add detections, invent IOCs or MITRE techniques, or change the score.

================================================================================
  7. TROUBLESHOOTING
================================================================================

  Q: "npm install" fails or is slow.
  A: Ensure Node.js 20+ (node -v). Delete node_modules + package-lock.json and
     re-run npm install.

  Q: Port 5173 (or 8000) is already in use.
  A: npm run dev -- --port 5174     /     uvicorn app.main:app --reload --port 8001

  Q: PowerShell blocks the venv activation ("running scripts is disabled").
  A: Run once in PowerShell:
       Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
     Then re-run the activation command.

  Q: Backend errors like "unexpected keyword argument".
  A: You installed into the global Python with clashing versions. Always use the
     venv and the pinned requirements.txt. Recreate it:
       Windows:  rmdir /s /q .venv  &&  python -m venv .venv
       Linux:    rm -rf .venv       &&  python3 -m venv .venv

  Q: Frontend shows mock data even though the backend is running.
  A: Check frontend/.env has VITE_USE_BACKEND=true, restart `npm run dev`, and
     confirm the backend is up at http://localhost:8000.

  Q: AI section says "unavailable".
  A: Ollama is not installed/running or no model is pulled. Install + pull a
     model, or accept the labelled deterministic fallback.

  Q: Blank page after login.
  A: Hard-refresh (Ctrl+Shift+R). Make sure you opened http://localhost:5173
     (not file://).

  Q: PDF download fails.
  A: The "Download report" button on the Report page calls the backend
     /report/pdf endpoint — the backend must be running and the investigation
     must have completed analysis (409 otherwise).
